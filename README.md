# 🎄 Christmas Advent Calendar — Interactive Landing Page

Una experiencia navideña digital e interactiva que combina animaciones, música clásica y un calendario de Adviento con 14 sorpresas.

Diseñada para que empresas y organizaciones puedan compartir mensajes, actividades, reconocimientos y regalos con sus colaboradores durante la temporada navideña.

## ✨ Características principales

- **Calendario interactivo:** 14 días con contenido personalizable.
- **Let it Snow:** botón que inicia la experiencia navideña.
- **Cascanueces animado:** personaje que protagoniza la transición hacia el calendario.
- **Efecto de nieve:** animación continua con opción de desactivarla.
- **Música navideña:** ambientación con *El cascanueces*, de Piotr Ilich Chaikovski.
- **Desbloqueo progresivo:** las sorpresas se habilitan automáticamente según la fecha.
- **Diseño responsive:** compatible con computadoras, tablets y dispositivos móviles.
- **Integración con HubSpot CMS:** versión adaptada para publicación como landing page.

## 🎁 Calendario de Adviento

El calendario contempla 14 días de contenido que pueden incluir:

- Mensajes motivacionales y de agradecimiento.
- Actividades y dinámicas de equipo.
- Regalos y sorteos.
- Reconocimientos especiales.
- Sorpresas navideñas.

**Nota:** Los contenidos, regalos y actividades son demostrativos y están sujetos a personalización.

## 🚀 Instalación y ejecución

### Versión local

1. Descargar o clonar el repositorio.
2. Abrir `Adviento_Propuesta_DEMO.html` en un navegador.
3. Presionar **Let it Snow** para iniciar la experiencia.
4. Explorar las 14 sorpresas.

La versión DEMO permite visualizar el contenido sin esperar las fechas de desbloqueo.

### Publicación en HubSpot

1. Ingresar al Design Manager de HubSpot.
2. Crear una plantilla HTML + HubL para landing page.
3. Incorporar el contenido de `Adviento_Propuesta_HubSpot.html`.
4. Verificar las etiquetas obligatorias `standard_header_includes` y `standard_footer_includes`.
5. Crear una landing page utilizando la plantilla.
6. Probar las interacciones y publicar.

## 📱 Compatibilidad

Diseñado para funcionar en navegadores modernos:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

Compatible con dispositivos de escritorio y móviles.

**Consideraciones técnicas:**

- La reproducción musical depende de las políticas del navegador.
- La activación por fecha se ejecuta en el navegador del visitante.
- El bloqueo del calendario es visual y no constituye un mecanismo de seguridad para contenido confidencial.
- Las ilustraciones y grabaciones musicales deben utilizarse conforme a sus respectivas licencias.
